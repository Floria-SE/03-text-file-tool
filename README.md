# 文書整理ツール

## 概要
文章の前後にある余分な空白や空行を削除し、各行に行番号を付けて整理するツールです。

## 機能
- テキストファイルを読み込む
- 各行の前後の空白を削除する
- 空行を削除する
- 各行に行番号を付ける
- 整理した文章を `output.txt` に保存する

## 学習したこと
- テキストファイルの読み込み・書き込み
- `with open()`：ファイルを安全に開く
- `.read()`：ファイルの内容を読み込む
- `.write()`：ファイルに文字列を書き込む
- `.splitlines()`：文字列を行ごとに分けてリストにする
- `.strip()`：文字列の前後の空白を削除する

## 実行方法
1. `input.txt` に整理したい文章を入力する
2. `main.py` をVS Codeで開く
3. 右上の三角マーク（実行ボタン）を押す
4. 整理後の文章がターミナルに表示され、`output.txt`（実行すると生成される）に保存される
